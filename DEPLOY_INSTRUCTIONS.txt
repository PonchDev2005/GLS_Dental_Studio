========================================
  GLS - Պատրաստ deploy-ի համար
========================================

Այս տարբերակում արդեն.
✓ data.js ավելացված է (բոլոր տվյալները)
✓ axios և json-server հանված են
✓ Բոլոր էջերը փոխված են static data-ի

Ինչպես աշխատեցնել.
1. npm install
2. npm start

Deploy (Vercel).
1. Նախագիծը դրիր GitHub
2. vercel.com → Import project
3. Build: npm run build
4. Output: build

ԿԱՐԵՎՈՐ.
public/images թղթապանակը պետք է ունենաս քո բնօրինակից
(նկարներ և տեսանյութեր)։ Այս zip-ում միայն կոդն է,
որովհետև մեդիա ֆայլերը շատ մեծ են (~50MB)։

Պարզապես քո հին public/images-ը պատճենիր այս նախագծի
public/ թղթապանակի մեջ։
